# Gorka Setien | Portfolio & Personal Web

Personal website and technical portfolio of **Gorka Setien** (@gorkaseto), deployed on **GitHub Pages**:
👉 **[https://gorkaseto.github.io/](https://gorkaseto.github.io/)**

## 🌐 Technologies & Theme
- **Aesthetic:** Refined, modern high-tech developer portfolio (Obsidian & Neon Cyan, calm typography, and subtle ambient accents).
- **Core:** Semantic HTML5, modern CSS3 (Custom Properties, Flexbox, CSS Grid, responsive design) and modular Vanilla JavaScript.
- **Featured Specializations:** 
  - **Artificial Intelligence & LLMs:** Spec-Driven Development (SDD via OpenSpec), autonomous multi-agent orchestration, Model Context Protocol (MCP) integrations, Context Engineering, and automation scripting.
  - **Spatial Computing & Virtual Reality:** Unity 3D, Virtual Reality (Pico XR Enterprise lineup: Pico Neo 3 Pro/Enterprise, Pico 4 Enterprise, Pico 4 Ultra Enterprise, Pico Project Swan / Space Pro; OpenXR), multiplayer networking (NGO, Photon), and data-oriented design with DOTS/ECS.
- **Key Features:**
  - Consolidated Specializations showcase with an integrated 4-step Spec-Driven Development (SDD) pipeline (*OpenSpec -> Orchestration -> Verification -> Deploy*).
  - Compact and collapsible interactive command console (`ai`, `about`, `stack`, `experience`, `contact`, `whoami`, etc.) with 1-click shortcut pills.
  - Smooth typewriter animation highlighting core competencies.
  - Subtle, calm ambient HTML5 canvas background.
  - 1-click clipboard copy feedback for the contact email.
- **Optimization:** Zero heavy dependencies, instantaneous loading, fully compatible with GitHub Pages via `.nojekyll`.

## 📁 Project Structure
```text
├── index.html        # Main DOM structure and SEO / OpenGraph metadata
├── style.css         # Modern high-tech design system and responsive styling
├── main.js           # Interactive logic (typewriter, terminal, canvas, clipboard)
├── .nojekyll         # Disables Jekyll processing on GitHub Pages
└── assets/           # Images and icons (Agumon Hakase avatar and GIF)
```
